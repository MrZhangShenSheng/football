## 写新回测的规矩

1. 时间线一律用 `common.strict_merged`，不要自己拼 `merged`。
2. 判据（命中率/收益率/显著性口径）在跑之前写进脚本头部，不看结果再挑。
3. 出了正收益先跑 `leak_audit.py` A/B 对照，再报。
4. **见到"命中率不如市场但收益率高出一截"，先查泄漏** —— 那是偷看答案后专挑冷门的指纹，
   不是发现了 alpha。
