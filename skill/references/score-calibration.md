# 比分校准与形状分散规范

## 目的

将“胜负方向判断”和“精确比分判断”拆成两个可审计对象。比分预测不得把强队方向自动转换成零封低比分，也不得把同一比赛剧本下的多个比分误认为分散覆盖。

## 赛前输出字段

每场比分候选至少记录：

- `score_source`：`freq_band`、`calibrated_matrix`、`market_only` 或 `fallback`；不得把 `dc` 的 `top_scores` 伪称为 freq-band。
- `score_probs_raw` 与 `score_probs_calibrated`：原始比分分布和经过历史校准后的分布。
- `p_home_win`、`p_draw`、`p_away_win`：由同一比分矩阵聚合出的方向概率，用于一致性检查，不替代独立胜平负锚。
- `p_clean_sheet_home`、`p_clean_sheet_away`、`p_btts`、`p_over25`：用于识别零封偏误和比赛开放度。
- `shape_family`：`home_clean_sheet`、`home_concedes`、`draw_low`、`away_clean_sheet`、`open_high` 等。
- `shape_coverage`：本场候选覆盖的形状族列表。

## 候选生成规则

1. 先以真实赛果频率和联赛/球队近况生成候选，再用独立市场仅作可买性、赔率时点和冲突标记；不得用体彩最低赔率直接排序。
2. 若生产管线实际使用 DC/Poisson 矩阵，必须明确标记 `score_source=dc_matrix` 或 `fallback`，不能与 SKILL 声称的 freq-band 默认链路混淆；先进入影子比较，不自动替代已验证链路。
3. 对明显热门主队，候选不能全部属于 `home_clean_sheet`。若 `p_away_goal>=0.35` 或市场/近况显示客队进球路径不低，至少保留一个 `home_concedes` 候选（例如 2:1、3:1、3:2，具体比分仍由分布决定）。
4. 对大热门强队，不得把 1:0、2:0、3:0 视为三个独立剧本；它们同属 `home_clean_sheet`，形状覆盖只计一次。
5. 单场最多保留两个同一形状族的候选；若资金或候选数允许，至少覆盖一个相邻形状族。未满足时报告“零封集中风险”，不能宣称已经分散。
6. 形状规则只作护栏，不直接制造概率。阈值（如 `p_away_goal`、形状族上限）必须经过时间切分回测；样本不足时标记实验规则，不调整正式概率。
7. 比分长串前，先计算每场的形状覆盖和联合全灭概率。二串一/三串的“容错”只容错腿数，不容错每场差一球；报告中必须明确这一点。

## 临场更新

官方首发和确认伤停优先更新进球分布的形状指标，而不只是平移胜平负概率：核心门将/中卫缺阵优先影响零封和客队进球尾部，核心前锋缺阵优先影响主队高比分尾部。没有确认核心影响时，调整应为区间并扩大不确定性，不得伪造精确点估计。

## 赛后复盘

每场同时记录：

- `direction_hit`：胜平负方向是否命中；
- `score_hit`：精确比分是否命中；
- `winner_error`：方向是否错；
- `total_goal_error`：实际总进球减预测中心总进球；
- `btts_error`：是否错误判断双方进球；
- `clean_sheet_error`：是否错误判断零封；
- `candidate_shape_hit`：候选是否至少覆盖实际形状族；
- `topk_hit`：实际比分是否进入前K候选。

复盘优先看 RPS、log loss、Brier/校准曲线和 CLV，不用单轮盈亏决定改规则。至少积累 50 场、且按联赛和赛季分层后，才考虑调整形状护栏；至少 100 场才允许正式替换比分概率源。

## 影子实验

在正式替换前并行保存三条评分：

- `dc_matrix`：当前 DC/Poisson 矩阵；
- `freq_band`：真实频率形状链；
- `hybrid_calibrated`：频率形状 + 经历史校准的进球分布。

每轮赛后对三者统一结算，按时间切分比较方向、精确比分、top-k、RPS、log loss、零封误报率和双方进球误报率。若新链没有在预设护栏（至少整体 RPS 改善1%，且零封误报率不恶化超过3个百分点）下胜出，继续影子运行，不改生产链。

## 本轮案例归档

2026-09-14/15 的六场复盘显示：方向 6/6，但比分 2/6；博德闪耀3:2和国米5:3暴露“强队零封/低总进球偏误”，科莫2:1暴露漏掉主胜丢球路径，布拉加1:0和罗马0:2命中。该案例只能作为触发实验和字段补齐的证据，不足以单独估计长期改进幅度。
