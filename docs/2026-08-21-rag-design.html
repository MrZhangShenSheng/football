二、学术 Review 修正（v2 核心变更）

P0修正 1 · 双锚制：概率锚与可买性分离

Pinnacle 收盘价（概率锚）体彩官方赔率（可买性）
用途去水得真实市场概率，参与融合判断能不能买、算奖金、算 CLV
毛利~2.5%>7%
来源oddsportal 存档 / Pinnacle 数据体彩官方 API（已有）

原因：体彩毛利 7% 本身引入 ~5pp 偏差，与原"偏差>5pp 告警"同量级，信号被噪声淹没。

P0修正 2 · 对比告警 → logit 融合

p_final = σ(a·logit(p_DC) + b·logit(p_pinnacle))   a≈0.3-0.5，回测校准，存 models/fusion.json

原因：文献结论"模型与市场正常分歧 <3pp，>5pp 多半是模型错"。融合比告警更有效利用模型增量。融合前后偏差 >3pp 仍输出注记（但不再是主信号）。

P0修正 3 · 回测基建（一切验证的地基）

  • walk-forward 逐轮前推验证（防数据泄漏）
  • 评估指标：RPS（主）+ log loss（辅）+ CLV（盈利性）；命中率仅作展示
  • 回测成交一律按 Pinnacle 收盘价计

四、检索与预测流程

Step 0   模式判定（全局 / 快速）
Step 1   体彩 API 抓赛程（可买性）+ odds_fetch 抓 Pinnacle 收盘价（概率锚）
Step 1.5 预筛选快排
Step 2   检索本地：_index → 球队画像 → DC 缓存新鲜度检查 → 只搜缺口
Step 3   计算：dc_predict → 7x7 矩阵 → 三向概率；elo/xg 过期则先 fetch
Step 3.5 融合：p_final = σ(a·logit(p_DC) + b·logit(p_pin))；偏差>3pp 注记
Step 4-6 Claude 推理：修正系数（消融清单内）→ 星级 → 串关
Step 7   报告 HTML → 03-predictions/；预测 JSON → 02-results/
Step 8   赛果回填 → 五维统计（含 CLV 逐场计算）

CLV 定义：出票赔率 vs Pinnacle 收盘赔率的收益率。打平收盘 ≈ 零期望；稳定打赢 1.5-2% ≈ 长期盈利代理。每单必记录，复盘以 CLV 为主指标。
