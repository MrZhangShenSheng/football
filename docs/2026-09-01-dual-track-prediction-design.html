HAD 市场直信轨 + 进球独立引擎轨 · 定稿于 2026-09-01 · 状态：设计定稿，未开发（P0/P1/P2 切片见第五节） · 决策人：大哥 · 依据：2026-09-01 会话研究 + 两轮实票逻辑解剖

一、设计缘起与观察

大哥观察：胜平负玩法中赔率大部分情况能体现真实结果趋势；比分玩法仅少部分情况与结果一致。2026-09-01 以 2310 场 fd 收盘数据 + 335 条 corpus 方案腿 + 1740 场 DC 比分矩阵验证，观察成立且可量化，遂将两玩法预测逻辑分化：方向玩法信市场，进球玩法走独立引擎。

2.3 两轮命中腿逻辑解剖（08-30 / 08-31，8 腿全中）

统一公式：市场锚概率（融合 b=1.0 主导 / 无锚联赛单锚先验）× 轻修正链（开季 R1×0.80 / R2×0.90、伤停系数、波动降档）→ 修正后 50~78% 低赔倾向腿。胜平负命中的功臣是市场锚而非 DC；而进球侧（T012 / upset 池）走裸 DC 的 q/EV 扫描、无任何修正因子，全 miss。08-31 巴萨 HHAD-2 腿（DC λ 3.20/0.47 直接算净胜≥3≈50.4% vs 市场 47.9%）命中，证明 λ 引擎在净胜/总进球类玩法上有信号，缺的是修正因子层——且该腿 note 里人工手写的伤停/近况系数正是修正层的原材料。

2.4 进球影响因素盘点

本地已有：联赛进球基线（意甲 2.37 ~ 荷甲 3.34，差 40%，第一锚）、主客场效应（主胜率 34~49%、主队得分占比 50~61%）、归因账本 F9 校准低估 39 例主导（avgProbGap 42%）。缺口：伤停结构化（体彩 insight 有源未字段化）、xG 对位（fd 主流联赛 hxg/axg）。

三、总体架构与数据流

核心原则：两轨不共享概率结论，只共享数据基建；DC 全部价值转移到进球轨做 λ 底座；体彩赔率永不作概率锚，只做可买性与 EV/派彩。

四、市场直信轨设计

概率公式：p_HAD = devig(Pinnacle 收盘三向)，不再与 DC logit 融合（fusion a 系数旁路）。DC 三向概率降级为报告对照展示列。

修正链保留（已验证有效的轻量先验，与 DC 无关）：开季轮次修正 R1×0.80 / R2×0.90；伤停系数（核心缺阵 → d 值乘子，对侧另计）；联赛波动降档（瑞超类 ×0.95）。修正后与市场隐含双向校验：修正把 62% 压到 55% 时降星或剔除。

无锚退化：fd 不覆盖联赛（瑞超/日职/沙特/韩职）沿用单锚先验（上轮收盘/联赛画像），报告标注"无市场锚，置信降档"。

准入与纪律：保底腿准入 = 市场隐含 ≥65%（该档实测腿级命中 70%+）；连败熔断——连续两轮保底 miss → 下轮注金减半，中一轮恢复；回血垫形状（4串5/4串11）与对冲腿比例维持 preference.json 现状。报告腿依据口径从"融合69%×R2"改为"市场69%×R2"。

爆冷风险说明：纯市场不改变选腿赔率带（由保底档口味定位决定），A 只让概率估计更准；尾部风险由门槛+熔断+垫结构管理，三者正交。
