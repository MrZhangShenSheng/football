## 一、方案概述

### 1.1 设计理念

**不用纯数学概率预测，用多场景规则博弈**

```
4个独立场景分析 → 计算比分信号 → 频率校准 → 2串1双选投注
```

## 三、场景规则

### 3.1 场景S1：攻防对比

| 条件 | 判断 | 支持效果 |
|------|------|----------|
| 主攻强(>1.8) AND 客守差(>1.5) | 主攻压制 | home_win +0.4 |
| 客攻强(>1.8) AND 主守差(>1.5) | 客攻有威胁 | away_win +0.3 |
| 双方进攻弱(<1.0) | 双方低迷 | low_score +0.4, draw +0.3 |
| 双方进攻强(>1.8) | 双方互爆 | high_score +0.4 |
| 其他 | 均衡 | draw +0.2 |

### 3.2 场景S2：近期状态

| 条件 | 判断 | 支持效果 |
|------|------|----------|
| 主状态好(>=7) AND 客状态差(<=3) | 主强客弱 | home_win +0.4 |
| 客状态好(>=7) AND 主状态差(<=3) | 客强主弱 | away_win +0.4 |
| 双方状态差(<=3) | 双方低迷 | low_score +0.3, draw +0.3 |
| 其他 | 状态接近 | draw +0.2 |

### 3.3 场景S3：零封能力

| 条件 | 判断 | 支持效果 |
|------|------|----------|
| 主零封强(>0.35) AND 客被零封高(>0.35) | 主零封倾向 | home_clean +0.4 |
| 客零封强(>0.35) AND 主被零封高(>0.35) | 客零封倾向 | away_clean +0.4 |
| 双方被零封高(>0.35) | 低产对决 | low_score +0.3 |

### 3.4 场景S4：大球倾向

| 条件 | 判断 | 支持效果 |
|------|------|----------|
| 双方大球率高(>0.55) | 大球倾向 | high_score +0.4 |
| 双方BTTS率高(>0.55) | 双方进球 | both_score +0.3 |

## 五、投注策略

### 5.1 2串1双选

```
每日选场：按最大信号排序，取前2场
每场选比分：按信号排序，取Top2比分
投注组合：2×2 = 4注
单注金额：2元
每日成本：8元
```

### 5.2 选场逻辑

```python
# 每日可选场次中，按 max_signal 排序
selected = sorted(day_packs, key=lambda p: -p["max_signal"])[:2]

# 每场选 Top2 比分
for p in selected:
    picks = p["sorted_scores"][:2]
```
