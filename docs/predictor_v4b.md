## 二、核心改进

### 2.1 状态加成（关键创新）

通过诊断发现：某些状态组合的命中率远高于平均值。

**A类：平局加成组合**

| 状态组合 | 命中率 | 加成系数 |
|:--------:|:------:|:--------:|
| (3, 5) | 58.3% | 0.4 |
| (5, 2) | 54.5% | 0.4 |
| (5, 5) | 53.8% | 0.35 |
| (2, 2) | 40.0% | 0.3 |
| (2, 1) | 40.0% | 0.3 |
| ... | ... | ... |

当状态组合在这些高命中组合中时，增加平局类比分（1:1, 0:0, 2:2）的信号。

**C类：主队主导组合**

| 状态组合 | 说明 | 加成系数 |
|:--------:|:----:|:--------:|
| (9, 0) | 主队满分，客队0分 | 0.2 |
| (9, 1) | 主队满分，客队1分 | 0.15 |
| (7, 0) | 主队7分，客队0分 | 0.15 |
| ... | ... | ... |

当主队状态远优于客队时，增加主胜比分（1:0, 2:0, 2:1）的信号。

### 2.2 加成系数

经过回测验证，**最佳加成系数为1.25**。

```python
BOOST_FACTOR = 1.25
```


```
投注组合：2×2 = 4注
单注金额：2元
每日成本：8元
```

### 5.2 选场规则

```python
# 按Top1信号强度排序，取前2场
for p in day_packs:
    p["max_signal"] = p["prediction"][0][1]
```
