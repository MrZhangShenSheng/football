LLM 语境预测层（llm-predict）设计

日期：2026-10-13 · 拍板：大哥（brainstorming 会话） · 定位：tail-model FAIL 后的真预测最后候选——项目收缩为数据收集+汇总层，决策时点把数据卡交给大模型做预测

§0 背景与合法性根基

三条已证伪 + 一条未证伪（本项目的立足点）
  • ❌ 历史统计数值模型（tail-model·2026-10-13：61 维特征 logistic/HistGB 肥尾 log-loss 显著输市场，CI 上限<0）
  • ❌ 赔率任何变换（铁律 13 数学锁）
  • ❌ 模型独立排序（四臂回测三窗垫底）
  • ✅ LLM 语境信息差（本项目）：大模型的独特优势不是算概率（换预测器不换信息集=白换，同样吃数学锁），是读懂赛前文本语境——伤停细节、轮换暗示、动机语境。这是两周来全部数值模型结构上碰不到的信息层，也符合"真预测=场次级信息优势"的必要条件，且不需要分钟级数据（赛前一两天到当天几小时的公开报道即可）

现实约束（大哥明确）：无分钟级数据通道；信息源=历史数据 + 网上可查的赛前数据。预测时点=体彩在售清单出来后到开赛前（小时级窗口，足够）。

防幻觉铁规：语境层每条信息必须带来源 URL；LLM 预测引用了哪条输入必须在证据标注里点名；检索不到=数据卡该层标"未获取"，LLM 不准编（铁律 1）。

§3 LLM 预测协议

每场输出 JSON：
{ "code": "周二001", "match": "阿森纳 vs 切尔西",
  "p_crs": {"0:0":0.04, "1:0":0.09, ..., "other_a":0.001},   ← 31 格（系统归一）
  "keyJudgments": [                                           ← 每场 3 条
    {"judgment": "厄德高伤缺，中场创造力降档",
     "evidence": "语境层#2（BBC 赛前报道，URL+时间）"}],
  "confidence": "medium" }
  • 31 格直接输出（非骨架条件链）：LLM 天然按比分分布思考；系统从 31 格聚合一切（E1/E2/E3/右尾腿概率），与 logistic 臂/市场三方同口径可比
  • 校准：初期 T=1 不动；样本 ≥100 后加温度缩放层（log-loss 受益）
  • 归一：31 格和≠1 → 系统归一（记录原始和，偏差大标记质量警示）

§4 判据预注册（engine/cache/llm-predict-prereg.json·先于一切代码 commit）

项冻结口径
主判据（大哥 2026-10-13 修正）31 格全分布：LLM p_crs vs 市场封盘 crs power devig（31 格同键），逐场配对 log-loss 差（market − llm，正=LLM 更准），bootstrap95 CI 下限>0——预测什么就对什么整体打分，零事件族挑选空间
次级报告（descriptive·非判据）①事件族 E1/E2/E3（同 tail-model 口径）②右尾肥尾格子域（赔率≥30 各格+0:3/0:4）log-loss 单列——供右尾决策参考，不进 PASS/FAIL
方法论红线forward only——LLM 见过历史赛果，历史回测=训练集考试=作弊；样本只来自预注册后的真实 forward（数据卡+预测均冻结落盘防事后改）
样本节奏每次"帮我预测"自动积累；n≥30 早期观察、n≥100 正式判定（约 3~5 周）
影子层family L「llm-31格选腿」第一天即跑（选腿=LLM 分布 top 腿过冷肥过滤：赔率≥30 或 0:3/0:4 档）
准入主判据 PASS → 幸存链注册 → 才影响实票推荐；FAIL → 数据卡资产保留，负结果归档

§6 限制与已知风险（诚实清单）

  • 搜索配额与语境层覆盖：语境层依赖联网检索（配额波动）；某场检索不到=该场信息集退化到自动层（与 tail-model 同=预期无优势），对拍按场分层报告
  • LLM 概率校准差：分布和归一/温度缩放只治标；若 LLM 输出严重尖峰化（个别格 >50%），质量警示并标记
  • 成本：会话内预测零 API 费，但每次预测流程多出检索+预测两步（分钟级人工等待）
  • 全分布判据的质量集中：31 格 log-loss 的信息量大部分来自热门格（1:1/1:0）——主判据赢≠右尾格赢，故右尾子域 log-loss 恒列次级报告，右尾决策以子域报告为准
  • 大概率 FAIL 的预算：这是真预测的最后一个候选；FAIL 后的诚实结论="体彩竞彩没有真预测，只有方差工程"（右尾定位全部保留）
  • 历史泄漏的边界：forward only 已锁死回测作弊，但 LLM 的训练数据截止晚于比赛日时（未来场次），其"知识"不含赛果——此边界随模型版本更新自然成立，无需额外防护
