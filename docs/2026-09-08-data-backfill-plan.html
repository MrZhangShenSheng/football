阶段1 · espn 别名补全（前置卡点）

  • 现状：荷甲两分组 22 队仅 5 队有 espn 字段（NEC/AZ/前进之鹰/海伦芬/埃因霍温FC 系）；「勿手填猜测」纪律禁止瞎写
  • 方法：写 scratch 脚本拉 ESPN standings（ned.1 等 11 个联赛代码）→ 提取 team.displayName 全集 → 与 _aliases.json 对应分组对照 → 确定性匹配（kebab 化精确匹配/首词唯一匹配）自动建议 + 模糊项列人工确认清单 → 确认后写回
  • 合规性：displayName 为 ESPN 实测值，映射到已有规范 ID 是确定性对照，不属猜测；确认不了的留 null 不硬填
  • 兜底：standings 缺队时用 history 第一遍的 dropped 日志清单（脚本已内建「丢弃样本（补 espn 字段可恢复）」提示）补第二遍
