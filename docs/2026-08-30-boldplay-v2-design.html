4.3 逐场三池玩法卡（Step 7 报告新增输出）


    

  • 每场 A/B 级场次一张卡：三池各取 top 选项（CRS=带内 q 最高 1 项；TTG=q 最高 2 档；HAFU=q 最高 2 键）并排：选项 / q 真实频率 / 体彩赔率 / EV
    • 

  • 推荐规则（v1.1 双行）：保底视角=EV 相近带（差 < 动态阈值）内取 q 最高者（命中优先）；翻身视角=相近带内取赔率最高者（右尾优先）——同 EV 的 25%@3.4 与 12%@24 对两档是相反的正确答案，单推荐必错其一
    • 

  • 动态阈值：max(0.05, 2×合并标准误)——样本小时阈值自动放宽，EV 微差让位给结构规则（抽水低池优先）；样本不足（n<100）不砍池不砍卡，改标"低置信"旗（q 基于 β 收缩先验，推荐按结构规则兜底）——大哥决议：小联赛（芬超/韩职）场次不能没有推荐
    • 

  • 全负 EV 如实标注"负EV娱乐注"（体彩常态，诚实呈现）
    • 

  • C/D 级不出卡（数据等级约束）；卡随预测 JSON 归档（matches[] 增 pools 字段：{crs:{pick,q,odds,ev}, ttg:{...}, hafu:{...}, recommend}）
    • 

  • 预测记录 schema：pools 字段随回填闭环（settle 判 pools.recommend 命中率 → trend ⑦ 新断言：推荐池 vs 实际最优池）
    •

5. 错误边界




情形处理


场次无 half_share（联赛缺半场先验）HAFU 池标注"先验缺失"不出候选，TTG/CRS 正常（聚合不依赖 half_share）


体彩 ttg/hafu 池未开售该池标 ❌ 跳过（odds dump 的池数据存在性检查）


三池 EV 全负如实标注，推荐列"最不差"+ 负EV 娱乐注标记（宁缺毋滥原则不变）


seq 轮换遇翻身腿不足奇数轮 2串1×3 需 ≥3 场有卡候选；不足降级 2串1×N（N=可用场数）或关档（铁律 8 不硬凑）


跨池腿同场相关性翻身引擎选腿硬约束：同场最多 1 腿（A场 CRS 2-0 与 A场 TTG 2球同生共死=变相加倍，非分散）


half_share.json 死数据实施前存活检查（amix 降级后 learn 链是否仍刷新）；死则先重建再启用 HAFU 聚合


legacy 过渡期双轨数据冲突各自独立 settle 账本，trend 报告分列；不合并统计

#决策理由备选与否决原因


D1双结构过渡（new 默认 + legacy 对照一个月）freq-band/amix 先例；真实数据继续积累直接切（失去对照）；回测先行（7 轮 0/21 已是回测结论）


D2两档制，进阶砍除5串1 七轮 0/7 最差实证三档瘦身（进阶 2串1×2 留尾——一个月后可议）


D3保底 = 4串1185.2% 回款概率 + T002/003 实证盈利 + 结算引擎现成（expand_combos）3串4（8元，更瘦但回款概率 66.8%）；4串15（含单关但成本 30 吞满预算）


D4翻身 = 多池引擎 + seq 轮换大哥观点+三池结构数据；缺实测故轮换对照纯彩票甲（19.1% 期望）；纯容错乙（失去翻身本义）


D5跨池 EV 对比合法（≠amix 找错价）q 源=真实频率；池间差=抽水结构纯抽水排序（丢场次信号信息）


D6HAFU v1 独立近似half_share 已有；条件分解需半场数据积累条件分解（数据不足，消融后升级）


D7逐场三池卡=A/B 级限定C/D 级数据等级不够（玩法×等级矩阵既有约束）全部场次出卡（噪声）


D8HAFU 经验纠偏系数 α（大哥讨论1决议）独立近似对 dd 方向性低估 30-50%，有偏估计不得进决策链；α 全局起步随回填重估区间化显示（知偏不修）；v1 不推荐 HAFU（排除大哥最有心得的玩法）


D9样本不足不砍池，降置信标注+动态阈值兜底（大哥讨论2决议）小联赛（芬超/韩职）场次不能没有推荐；动态阈值 max(0.05,2×SE) 连续处理样本量硬门槛 n≥100 不出卡（砍掉大哥常用联赛）


D10双行推荐：保底视角/翻身视角（大哥讨论3决议）同 EV 的稳选/右尾选对两档是相反正确答案，单推荐必错其一单推荐+脚注；单 EV 排序


D11legacy 独立文件 + 回测范围改写 + 定夺标准分级（红队审查修正）防同日覆盖；翻身多池不可历史回放是事实必须写明；单月只出方向性结论同名文件双写（互相覆盖）；回测含翻身档（不可执行）
