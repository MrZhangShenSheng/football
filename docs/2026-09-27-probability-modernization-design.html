一、第一梯队（第一期开发 · 数据全就绪 · 约 1.5 天）

① 概率校准层（isotonic · 最高 ROI）

问题（E1）：输出概率与实际频率系统性偏离 22pp，整个下游（星级/EV/串关连乘）都建立在未校准概率上。

方案：对 corpus 298 场的 (p_final[pick], directionHit) 对做 PAVA 保序回归（自实现，不引 sklearn），输出分段线性映射表。

corpus.json records → (p̂, hit) 298对 → PAVA 单调拟合 → 前80%拟合 / 后20%时间外验证(OOT) → engine/cache/isotonic.json（分段断点+映射值+n支持数）

护栏（本期不动生产链）：只落盘映射表+校准前后 reliability 报告；观察一个回填周期后按消融纪律决定是否接线进 dc_predict/boldplay（无正增益即不接）——沿用修正系数消融纪律。

验收：映射表单调；OOT 校准后 |预测−实际| 收敛（目标：低桶偏差 22pp → <10pp）；报告 data/04-summaries/isotonic-report.json。

新文件：engine/scripts/calibrate_isotonic.py（PAVA 自实现+selftest）。

② xG-λ 对比实验（信号源升级评审）

问题（E5）：λ 从进球数拟合=从噪声拟合（进球含运气分量）；fd 的 HxG/AxG 是更干净的信号。

方案：dc_fit.py 加 --lambda-source=xg|goals 开关，同 train/test 划分对比两种 λ 源的 holdout logloss。

fd CSV(HxG/AxG, 缺失场次剔除) → λ_xg 拟合 vs λ_goals 拟合 → 同划分 holdout logloss 对比（总体+分联赛） → data/04-summaries/xg-experiment-report.json → 结论二选一: 建议 dc_fit 默认换源 / 证据不足维持(写明数据量)

验收：≥3 个主流联赛 holdout logloss 对比表；xG 覆盖率统计（缺失率>30% 的联赛标"不适用"）；结论写入报告（换/不换+依据），不自动切换默认值（换源=大哥拍板项）。

③ 自有 CLV 接线（同庄家时序口径）

问题（E3）：体彩 vs Pinnacle 的 CLV 结构性恒负（抽水差 13pp），衡量不了选单能力；真正口径=同庄家时序（出票时体彩价 vs 体彩最终价）。

方案：新脚本扫描 data/05-trends/*-odds.json 时序链，对每条已结算票腿：出票冻结价（tickets.json odds 字段）vs 该场**最后一次快照价**→ clv_self = 冻结价/最终价 − 1，写回票腿字段。

tickets.json 已结算腿 → 05-trends 快照链取该场末次价 → clv_self 逐腿写回 → tickets.html 增列 → 汇总场均 clv_self

诚实标注：trends 快照自 2026-08-30 起积累——只有近月票可算，早期腿 clv_self=null 标"时序未覆盖"；最终快照≠真实收盘（停售后无价），标注口径近似。

验收：对 09 月已结算实票跑通并出汇总（场均 clv_self 正负分布）；tickets.html 显示新列。

新文件：engine/scripts/self_clv.py。

④ 传足平局暴露检查（26132 死因直击）

问题（E4）：grasp=max(p_fused) 的 argmax 单式必然 0 平局（平局概率几乎从不为三向最高），而历史开奖期望 ~3.25 平/期+pari-mutuel 稀注杠杆。

方案：ren9.py 的 ren9() 输出后加暴露检查+复式贪心修正：

core9 → Σp_draw 期望值 E_draw + argmax 平局数 n_draw → n_draw==0 且 E_draw≥2.0 → warning: drawExposure → 复式贪心增益比修正: 平局双选 gain × 平局杠杆系数(默认1.5·pari-mutuel稀注) → 输出 drawGuard 字段(报警+建议双选名额分配)

回放验收（硬标准）：对 26132 重放——澳巴（友谊赛+客胜胆）与波兰（主胜开平）应被 drawGuard 建议平局双选或降级；26131（4 平期）重放报警触发。

二、第二梯队（第二期 · 建模升级 · 各约一天）

⑤ Shin 去水统一

HAD 三向比例归一 + CRS power 去水的双轨制统一为 Shin(1993) 内幕交易模型（体彩票池 FLB 最重场景）；实现 z 参数数值解+三向概率输出，替换 devig() 内核，power 去水保留在 CRS 池作对照。验收：对历史 298 场做 Shin vs 比例归一的 RPS 对比，改善 <1% 不切换（护栏）。

⑥ 传足 pari-mutuel 期望效用选场

argmax top9 → edge 最大化（p_true − p_crowd）。p_crowd 无直接数据时的近似：热门偏差先验（赔率倒数平方加权）+ okooo 投注比例探测（数据可得性 spike 先行）。产出 ren9.py v1 选场函数，与 v0 并行输出对比三期后拍板。

⑦ 平局亲和度连续分

平局轨二值门槛（p平≥28%+极差<12pp）→ 连续分 draw_affinity = f(λ_sum, |λ_h−λ_a|)（泊松下 P(draw)=Σ_k P(H=k)P(A=k) 解析式，k≤3 主项）；输出每场连续分+分位排名，阈值改分位数（如 top 15%）。验收：历史平局场（n=21 条推平腿）的 affinity 显著高于非平局场（AUC≥0.6）。

三、第三梯队（第三期 · 架构级 · 各 2-3 天）

⑧ Bayesian hierarchical λ（不确定性传播）

球队攻击/防守参数带先验的层次模型（PyMC 或 Stan 简化版），小样本联赛自动输出宽区间→星级自动下调（替代手工 ×0.97 单锚补丁）。前置：①校准层完成（否则校准的是噪声）。

⑨ 任9 轮内相关性建模

全中概率≠连乘（共同冲击：天气/裁判/轮换潮）。单因子 copula 或共同因子 λ 扰动近似；先用历史期次做重放验证连乘高估幅度，再决定建模深度。前置：④上线路径依赖平局检查积累 3+ 期数据。

⑩ drift 特征进融合

odds 快照时序的 drift（开售→出票时点）作为特征进融合公式（市场动量增量信息，低流动性联赛最强）。前置：③自有 CLV 接线+积累两个完整月时序。odds_drift.py 从"解读工具"升级为"特征提取器"。

四、纪律（不做什么）

  • 298 场语料撑不起深度学习——任何神经网络/GBDT 大特征提案直接拒绝（Groll 2018 用的是数千场级）
  • 不自动切换生产默认值——①映射表、②λ 源、⑤去水内核全部走"离线报告→大哥拍板→接线"三步，与修正系数消融纪律同构
  • 不过度设计——三梯队每期做完评估下一期 ROI，第三梯队任何一项若前两期已解决底层问题（如校准层吸收了大部分断裂），砍掉不做
  • 单写会话纪律——每期开发单独会话，先 git pull，结束 commit
