目标：落地统一比分分布引擎 P0——两个侦察（水位结构/fd代理源）+ 剧本轨接 DC 矩阵（P1.5 消账）+ market_matrix 五池拟合 + score_engine 融合出口。

全局约束

  • 剧本轨边界：narrative 不算 EV、不参考市场定价出票；市场分布只喂分歧度（选场排序）。
  • HAD 层边界：fused 矩阵三向边缘禁止回流 HAD 融合（防双重融合）。
  • 对照期内 boldplay/freq_band 主链口径冻结不动（本 P0 不触碰 freq_band.py 业务逻辑）。
  • 常量命名 UPPER_SNAKE_CASE，变量 camelCase；魔法值禁用（入常量）。
  • 侦察脚本放 engine/scripts/scratch/（gitignore，一次性）；结论回写设计文档 HTML。

"""侦察1: 体彩CRS池水位结构实测(设计§四).
冷热比分抽水是否均匀 → 幂次去水 alpha 选型.
判据: CRS去水分布的三向/TTG边缘 vs HAD/TTG池去水分布, JSD 最小者胜."""
import json, glob, math

ALPHAS = [1.0, 0.9, 0.8, 0.7]          # 幂次扫描: 1.0=等比例
SUPPORTED_OTHER_KEYS = ('胜其他', '平其他', '负其他')  # 以 Step1 实测为准替换

def load_matches():
    rows = []
    for f in sorted(glob.glob('engine/cache/score_odds/*.json')):
        for md in json.load(open(f)).get('matchDays', []):
            for m in md.get('matches', []):
                if m.get('crs') and m.get('had') and m.get('ttg'):
                    rows.append(m)
    return rows

def devig_pool(odds: dict, alpha: float) -> dict:
    """幂次去水: p_i ∝ (1/o_i)^alpha 再归一. alpha=1 等比例."""
    w = {k: (1.0 / float(v)) ** alpha for k, v in odds.items()}
    s = sum(w.values())
    return {k: v / s for k, v in w.items()}

def outcome_of(key: str) -> str:
    """比分/兜底键 → 'H'|'D'|'A'."""
    if key in SUPPORTED_OTHER_KEYS:
        return {'胜其他': 'H', '平其他': 'D', '负其他': 'A'}[key]
    h, a = (int(x) for x in key.split(':'))
    return 'H' if h > a else ('D' if h == a else 'A')

def crs_margins(p_crs: dict) -> dict:
    out = {'H': 0.0, 'D': 0.0, 'A': 0.0}
    for k, v in p_crs.items():
        out[outcome_of(k)] += v
    return out

def jsd(p: dict, q: dict) -> float:
    """Jensen-Shannon 散度(bit). p,q 同键集."""
    m = {k: (p[k] + q[k]) / 2 for k in p}
    def kl(a, b):
        return sum(a[k] * math.log2(a[k] / b[k]) for k in a if a[k] > 0)
    return 0.5 * (kl(p, m) + kl(q, m))

def main():
    rows = load_matches()
    print(f"[water_probe] 场次={len(rows)}")
    for alpha in ALPHAS:
        ds_had, ds_ttg = [], []
        for m in rows:
            p_crs = crs_margins(devig_pool(m['crs'], alpha))
            p_had = devig_pool(m['had'], alpha)
            ds_had.append(jsd({k: p_crs[k] for k in 'HDA'},
                              {k: p_had.get(k, p_had.get(k.upper(), 0.0)) for k in 'HDA'}))
            # TTG 边缘对照: CRS按总进球聚合 vs TTG池(键集以实测为准)
            p_t = devig_pool(m['ttg'], alpha)
            t_crs = {}
            for k, v in devig_pool(m['crs'], alpha).items():
                if ':' in k:
                    t = min(int(k.split(':')[0]) + int(k.split(':')[1]), 7)
                    t_crs[t] = t_crs.get(t, 0.0) + v
            t_pool = {int(k): v for k, v in p_t.items() if str(k).isdigit()}
            ks = set(t_crs) & set(t_pool)
            if ks:
                ds_ttg.append(jsd({k: t_crs[k] for k in ks}, {k: t_pool[k] for k in ks}))
        ds_had.sort(); ds_ttg.sort()
        med_h = ds_had[len(ds_had)//2]; med_t = ds_ttg[len(ds_ttg)//2] if ds_ttg else -1
        print(f"alpha={alpha}: HAD边缘JSD中位={med_h:.4f}  TTG边缘JSD中位={med_t:.4f}")
    print("[water_probe] 选型: JSD 最小且明显优于等比例(alpha=1.0)者 → ALPHA_SELECTED; 否则 1.0")

if __name__ == '__main__':
    main()

注意：had/ttg 池的键名（H/D/A 或 胜/平/负）以存档实测为准，先 python3 -c "print(list(m['had'].items())[:5])" 看一眼再对齐键。

import math
import numpy as np
from dc_predict import score_matrix

def _script_layer(m, style, dc=None):
    """⑤剧本层(P1落地·设计§五①): λ→score_matrix→剧本域argmax.
    dc={'lh','la','rho'}缺→降级风格模板(旧路径), source标记口径."""
    if dc and dc.get('lh') and dc.get('la'):
        mat = score_matrix(dc['lh'], dc['la'], dc.get('rho', 0.0))
        best = max(SCRIPT_UNIVERSE, key=lambda s: mat[int(s[0]), int(s[2])])
        p = float(mat[int(best[0]), int(best[2])])
        return {'score': best, 'prob': p, 'source': 'matrix'}
    top = style.get('top') or ('1:1', SCRIPT_PROB_EST)
    return {'score': top[0], 'prob': top[1], 'source': 'style'}

def divergence(mat, crs_odds, alpha=1.0):
    """叙事矩阵 vs 体彩CRS去水分布 JSD——只做选场排序,不算EV(设计§五①边界)."""
    w = {k: (1.0 / float(v)) ** alpha for k, v in crs_odds.items()}
    s = sum(w.values())
    q = {k: v / s for k, v in w.items()}
    jsd_v, support = 0.0, 0.0
    for k, qk in q.items():
        if ':' in k:
            p = float(mat[int(k[0]), int(k[2])])
            m = (p + qk) / 2
            if p > 0: jsd_v += 0.5 * p * math.log2(p / m)
            if qk > 0: jsd_v += 0.5 * qk * math.log2(qk / m)
            support += p + qk
    return jsd_v / support if support > 0 else 0.0

"""market_matrix: 体彩五池→市场比分分布参数(设计§三·P2).
分池幂次去水(alpha=侦察1选型) + DC参数(λm主,λm客,ρm)拟合复现五池价.
CRS池降级开关: 侦察1若判冷热抽水扭曲, USE_CRS=False只拟合HAD+TTG."""
import numpy as np
from scipy.optimize import minimize
from dc_predict import score_matrix

ALPHA_DEFAULT = 1.0        # ← 侦察1 ALPHA_SELECTED 回填
USE_CRS = True             # ← 侦察1 若降级改 False
FIT_ERR_GATE = 0.02        # 拟合误差门槛, 超出调用方降级 dc_only
LAMBDA_BOUNDS = (0.2, 4.5) # 与 freq_band LAMBDA_CLAMP 同源
RHO_BOUNDS = (-0.2, 0.2)
W_CRS, W_HAD, W_TTG = 1.0, 1.0, 0.5   # 池权重: CRS信息最多, TTG边缘部分冗余

def devig_pool(odds, alpha=ALPHA_DEFAULT):
    """幂次去水: p_i ∝ (1/o_i)^alpha 归一(与侦察1 water_probe 同式)."""
    w = {k: (1.0 / float(v)) ** alpha for k, v in odds.items()}
    s = sum(w.values())
    return {k: v / s for k, v in w.items()}

def _matrix_prices(lh, la, rho):
    """DC矩阵 → {'crs':{比分:概率}, 'HDA':{...}, 'ttg':{...}} 供loss比对."""
    mat = score_matrix(lh, la, rho)
    crs = {f"{h}:{a}": float(mat[h, a]) for h in range(6) for a in range(6)}
    crs['胜其他'] = float(mat[np.tril(mat, -1)[6:, :].sum() if False else 0.0])  # 6+球域外和, 以7x7截断口径实现
    hda = {'H': float(np.tril(mat, -1).sum()), 'D': float(np.trace(mat)),
           'A': float(np.triu(mat, 1).sum())}
    ttg = {str(t): float(sum(mat[h, a] for h in range(7) for a in range(7)
                             if h + a == t)) for t in range(8)}
    return crs, hda, ttg

def fit_lambdas(crs, had, ttg, alpha=ALPHA_DEFAULT):
    """→ {'lh','la','rho','fit_err'}; Nelder-Mead, x0=联赛先验或全局默认."""
    p_had = devig_pool(had, alpha)
    p_ttg = devig_pool(ttg, alpha)
    p_crs = devig_pool(crs, alpha) if (USE_CRS and crs) else None

    def loss(x):
        lh, la, rho = x
        if not (LAMBDA_BOUNDS[0] <= lh <= LAMBDA_BOUNDS[1] and
                LAMBDA_BOUNDS[0] <= la <= LAMBDA_BOUNDS[1]):
            return 1e3
        rho = max(RHO_BOUNDS[0], min(RHO_BOUNDS[1], rho))
        m_crs, m_hda, m_ttg = _matrix_prices(lh, la, rho)
        e = W_HAD * sum(abs(m_hda[k] - p_had[k]) for k in m_hda)
        e += W_TTG * sum(abs(m_ttg[k] - p_ttg[k]) for k in p_ttg if k in m_ttg)
        if p_crs:
            e += W_CRS * sum(abs(m_crs[k] - p_crs[k]) for k in m_crs if k in p_crs)
        return e

    res = minimize(loss, x0=[1.3, 1.1, -0.05], method='Nelder-Mead',
                   options={'xatol': 1e-4, 'fatol': 1e-6, 'maxiter': 800})
    lh, la, rho = (float(res.x[0]), float(res.x[1]),
                   max(RHO_BOUNDS[0], min(RHO_BOUNDS[1], float(res.x[2]))))
    return {'lh': lh, 'la': la, 'rho': rho, 'fit_err': float(res.fun)}

"""score_engine: 统一比分分布出口(设计§三).
λ空间log加权融合(市场主导) → 7×7矩阵. source=fused|dc_only, 全程带dcVersion(防对照期版本混杂·设计§七)."""
import json
import math
import dc_predict
from market_matrix import FIT_ERR_GATE   # 与拟合侧同源门槛

W_DC_INIT = 0.29   # 初始启发式: HAD侧0.4/1.0归一移植, 段A回测重标定(设计§三权重声明)

def _latest_dc_version() -> str | None:
    try:
        with open('engine/cache/models/latest.json', encoding='utf-8') as f:
            return json.load(f).get('version') or json.load(f).get('published')
    except Exception:
        return None

def matrix(lh_dc, la_dc, rho_dc, mkt=None, w_dc=W_DC_INIT, dc_version=None):
    """统一出口: mkt=None或fit_err超门槛 → dc_only降级(设计§三降级链)."""
    dc_version = dc_version or _latest_dc_version()
    if mkt is None or mkt.get('fit_err', FIT_ERR_GATE) > FIT_ERR_GATE:
        return {'matrix': dc_predict.score_matrix(lh_dc, la_dc, rho_dc),
                'source': 'dc_only', 'lambda': {'lh': lh_dc, 'la': la_dc},
                'w_dc': 0.0, 'dc_version': dc_version}
    w_m = 1.0 - w_dc
    lh = math.exp(w_dc * math.log(lh_dc) + w_m * math.log(mkt['lh']))
    la = math.exp(w_dc * math.log(la_dc) + w_m * math.log(mkt['la']))
    rho = mkt.get('rho', rho_dc)
    return {'matrix': dc_predict.score_matrix(lh, la, rho),
            'source': 'fused', 'lambda': {'lh': lh, 'la': la},
            'w_dc': w_dc, 'dc_version': dc_version}

注意：_latest_dc_version 的字段名以 engine/cache/models/latest.json 实测结构为准（执行时先 cat 一次），读不到返回 None 并在出口 dict 保留键。
