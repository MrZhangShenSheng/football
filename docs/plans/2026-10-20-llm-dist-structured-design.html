〇、一句话定位

把 LLM 轨的预测输出从「手填 31 格」（每场即兴作画、不可复现、无预算约束）改为结构化三参数输入 → 机器确定性生成分布 → 机器守预算与幅度（可复现、可消融、可归因）。臣的判断收缩到三个真正有信息量的决定：方向质量 · 比赛画面选型 · 证据等级。

三、批一核心：预测输入 v3.6 schema

{
  "code": "周二006",
  "direction":  {"h": 0.30, "d": 0.25, "a": 0.45},   // 三向质量，和=1（唯一的方向决定权）
  "evidenceTier": "structural",                        // state|structural|info → 叫板幅度上限 2/8/∞pt
  "shape": {"type": "open",                            // crush|lock|leaky|open 四型选一（matchPlay.script 定型）
             "xgSum": 3.1, "xgDiff": 1.2},             // xG 双参数（卡内 xg 层，no_data 可 null）
  "cellOverrides": {"0:3": 0.045},                     // 显式格级覆盖，≤5 格（真格级信息差的唯一口子）
  "keyJudgments": [ ... ],                             // ≥3 条不变；evidence 须标证据等级
  "confidence": "medium"                               // 信息薄（无伤停明细且无 xG）强制 low
}
臣不再写 31 格。格由生成器算，预算由校验器守。cellOverrides 是留给「我有市场没有的格级情报」的显式通道，超出 5 格即拒绝——006 型（1:1 比市场肥）走此口。

四、形状生成器算法（确定性）

4.1 五步生成

步操作公式/规则
① 市场带内形状市场 devig 分布按三向分组取带内比例cond[d][k] = mkt[k] / Σ mkt[带d]
② 三向分摊臣三向质量 × 市场带内比例p[k] = direction[d(k)] × cond[d(k)][k]
③ 模板调形四型模板对指定格乘权重见 4.2 模板表
④ xG 双参数有 xG 数据时二阶调整xgSum≥2.8 → 总球≥4 格 ×(1+0.3·(xgSum−2.8))；|xgDiff|≥0.8 → 净胜≥3 格 ×(1+0.4·(|xgDiff|−0.8))（封顶 ×2，方向按 xgDiff 符号）
⑤ 覆盖+归一cellOverrides 直接赋值（后归一）归一后得 31 格

4.2 四型模板（格形指纹）

型画面加权格（×权重）减权格（×权重）
crush 碾压强队主场拆铁桶3:0/4:0/3:1/4:1 ×1.81:1/0:0 ×0.7
lock 铁桶双低产出/一摆一磨0:0/1:0/0:1/1:1 ×1.5总球≥4 全格 ×0.5
leaky 互漏双方防线漏、门将差2:2/3:2/2:3/3:3 ×1.8零封格全 ×0.6
open 对攻开放互攻有来有回1:2/2:1/2:2/1:1 ×1.30:0 ×0.6
模板权重从宽起步（±30% 级），每 30 场按校准账回调——防 8 场样本过拟合（风险表 R2）。

五、freeze 改造（llm_pred v3.6）

5.1 校验器（拒冻级）

校验规则违者
大球预算（P6/P20）|臣(总球≥4 带质量) − 市场| ≤ 2pt拒冻 + 逐格/逐项打印差异（禁静默）
单格比值（P10/P11）格概率/市场同格 ∈ [0.5, 2.5]（other_* ∈ [0.3, 3]）；cellOverrides 豁免但须 kj 引格级证据
带宽锚（P9）|臣 TTG 期望 − 市场| ≤ 1.5 球；越带须 shape.xgSum 支撑
幅度挂钩（P8）max(direction) − max(market 三向) ≤ 证据等级上限（state 2pt / structural 8pt / info 不限）

5.2 警告级（留痕不拒）

方向和偏离市场 >12pt；cellOverrides 恰用满 5 格；evidenceTier=state 且有 xG 数据（该用 structural 却标低）。全部落 checks 块随卷存证。

5.3 价值格清单（P25 轻量版）

冻结时自动计算并附卷：valueCells = [{k, p_llm, p_mkt, ratio} | ratio>1.5 且 p_llm>3%]——供出票轨参考，不自动出票。

5.4 旧链保留

v2 手填冻结路径保留（--format=v2）作 fallback 与对照；structured 卷 chain="llm-31grid-v3"。

九、验收标准（当卷可见）

① 新卷大球带每场与市场差 ≤2pt；② 单格全落 [0.5,2.5]（覆盖格除外）；③ 校验零拒冻误伤（真判断不被错杀）；④ 回放对账 003 型损失收窄。累计目标（n=100 时判）：diffMean 从 −0.18 收向 −0.05~0——止亏+可度量，不承诺转正（转正取决于料，见影响交底）。

十、风险与回退

#风险缓解
R1判断空间收窄漏用真格级情报cellOverrides ≤5 格口子+kj 证据豁免；校验报告显式提示「本场未用覆盖」
R2模板/阈值过拟合 8+46 场权重从宽（±30% 级）；每 30 场按校准账回调；阈值改动留 commit 痕
R3工程量一日、今晚轮次冲突周二轮用旧机制跑；周三起新机制首跑
R4结构化卷再断代致积累慢genCohort 分层如实标注；判据不变，样本连续积累
R5生成器 bug 静默出错测试八项+回放对账+checks 块全落盘（禁静默纪律全适用）

十一、批二~四摘要（另出小设计）

批二：证据分级表（state≤2pt/structural 4~8pt/info 不限）+伤停三问+对手均位差>5 位七折+llm_eval 增 confidenceSplit 与 genCohort 分层+kj_settle 判定器（方向/格级/TTG 三类规则化判对错→attribution 累计）。批三：n≥100 校准重估（比分档+方向端），2.5~5% 档若续立→右尾选腿专项 prereg。批四：预测链末尾自动写 02-results 终审卷；闯关票按开赛日传参（待拍板）；无 xG 联赛状态上限降 1pt；价值格清单接出票参考；临场预警位挂伤停轨门。
