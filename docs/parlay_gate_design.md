# 闯关票策略设计文档

> 版本：v2.0 | 更新：2026-09-29 | 作者：sszhang

## 1. 策略概述

### 1.1 目标
用比分预测模型在竞彩市场获取正期望收益。

### 1.2 核心思路
- **模型选场**：用族模型预测比分概率，选"模型最确定"的场次
- **动态选腿**：根据模型确定度决定每场选几个比分
- **以小博大**：2串1复式结构，靠高倍回报覆盖多数失败

### 1.3 最终配置

| 参数 | 值 | 说明 |
|---|---|---|
| 特征版本 | v2 (26维) | 原始基线特征 |
| 温度 | T=1.0 | 无调整，最稳定 |
| 选场 | gap 前2 | 2天窗口内模型确定度最高的2场 |
| 选腿 | 动态1-2选 | gap > 0.05 选单选，否则双选 |
| 结构 | 2串1复式 | 1~4注 × 2元 |

## 2. 核心概念

### 2.1 Gap（模型确定度）

**定义**：模型预测的 top1 比分概率 - top2 比分概率

```
gap = P(top1) - P(top2)
```

**意义**：
- gap 大 → 模型很确定 → 值得信任
- gap 小 → 模型不确定 → 需要保险

**实证数据**（2153场）：
- gap > 0.08：1.2% 场次
- gap > 0.05：7.2% 场次
- gap > 0.03：22.9% 场次

### 2.2 动态选腿

**传统做法**：每场固定选2个比分（双选）

**优化做法**：根据 gap 动态调整
- gap > 0.05 → 选1个（单选）：模型确定，不浪费成本
- gap ≤ 0.05 → 选2个（双选）：模型不确定，买保险

**效果对比**（203票）：

| 策略 | 成本 | 盈利率 |
|---|---|---|
| 固定双选 | 1624元 | -11.6% |
| 动态1-2选 | 1194元 | **+4.6%** |

**提升原因**：
1. 成本下降 27%
2. 命中率保持
3. 单选命中时赔率更高

### 2.3 族模型（Family Model）

**比分族分类**：

| 族 | 比分模式 | 示例 |
|---|---|---|
| home_clean | 主胜零封 | 1:0, 2:0, 3:0 |
| home_multi | 主胜多球 | 3:1, 4:2 |
| draw | 平局 | 0:0, 1:1, 2:2 |
| away_clean | 客胜零封 | 0:1, 0:2 |
| away_multi | 客胜多球 | 1:3, 2:4 |
| other | 其他 | 高比分平局等 |

**两阶段预测**：
1. 预测族概率：P(home_clean), P(draw), ...
2. 族内分配：按历史频率分配具体比分

### 2.4 特征设计（26维 v2）

**主队特征（13维）**：
- 场均进球/失球（主客场分开）
- 进球/失球方差
- 零封率、被零封率
- 多球率、大球率
- 联赛均值比
- 历史场次
- 近期动量

**客队特征（13维）**：同上

**关键发现**：
- 最重要：进球方差（gf_var）
- 有害：历史场次（n_matches）移除后族准确率提升但盈利率下降
- 冗余：联赛均值比（lg_gf_ratio）与场均进球高度相关

## 3. 验证方法论

### 3.1 多切分点验证

**问题**：单一切分点可能过拟合

**方法**：用8个不同切分点验证稳定性

| 切分点 | 盲测场 | 盈利率 |
|---|---|---|
| 2025-12-01 | 2500 | +0.9% |
| 2026-01-01 | 2153 | +4.6% |
| ... | ... | ... |
| 2026-07-01 | 692 | +66.7% |

**标准**：全部切分点正收益才算稳定

### 3.2 特征重要性分析

**方法**：置换重要性（Permutation Importance）
- 打乱某特征
- 观察准确率下降多少
- 下降多 = 该特征重要

**发现**：
- 正向关键：gf_var (+1.7%), ga_home (+0.7%)
- 负向有害：n_matches (-1.25%)

### 3.3 指标选择

**族准确率 vs 盈利率**：
- 不是正相关！
- 优化族准确率可能降低盈利率
- 最终指标：**盈利率**

### 3.4 参数网格搜索

测试多参数组合，选最优：
- 温度 T：0.7, 0.8, 0.9, 1.0
- Gap 阈值：0.03, 0.04, 0.05, 0.06, 0.08
- 赔率权重 alpha：0.7, 0.8, 0.9, 1.0

## 4. 关键教训

### 4.1 小样本不可信

| 样本量 | 盈利率 | 可信度 |
|---|---|---|
| 70票 | +66.7% | ❌ 运气成分大 |
| 203票 | +4.6% | ⚠️ 参考 |
| 232票 | +0.9% | ✅ 保守估计 |

**原则**：以最大样本的结果为基准

### 4.2 过度优化陷阱

**温度调整案例**：
- T=0.8 在单一切分点 +64.6%
- 多切分点验证：7/8 正收益，1个亏损
- T=1.0：8/8 全部正收益

**结论**：选稳定性而非最高收益

### 4.3 族准确率 ≠ 盈利率

移除 n_matches 特征：
- 族准确率：24.99% → 26.75% ✅
- 盈利率：+4.6% → -1.42% ❌

**原因**：影响了 gap 分布，导致成本上升

### 4.4 赔率无增量信息

模型+赔率融合 vs 纯模型：
- alpha=1.0（纯模型）效果最好
- 赔率已被市场充分定价

## 6. 预期与纪律

### 6.1 预期收益
- 保守估计：+1% ~ +5%
- 乐观估计：+20% ~ +30%
- 命中率：~7%（14/203票）

### 6.2 右尾结构
- 多数票归零
- 靠少数高倍命中回本
- 连续数月0回款是常态

### 6.3 运营纪律
- 满100注或连续3个月0回款再评估
- 中途不停
- 每日一票，幂等出票
