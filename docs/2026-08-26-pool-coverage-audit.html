② 三步设计摘要 + 参数实值

步骤 1：三域重标定（design §4）

target 三向（融合 + 因子修正后）→ reweight_matrix（IPF structure conservation 特例，域内 odds ratio 守恒）+ reweight_hafu。

护栏：①target 和=1(±0.001)否则报错 ②target<0.01 clamp+warn ③source 字段标注（裸 DC 修正禁直传）④before/after 同 JSON 输出

步骤 2：池级温度（design §5）

p_T(k) ∝ p(k)^(1/T)，每池一标量；T>1 平滑（修 DC 过度自信尾部）。作用顺序铁定：先重标定后温度（矩阵三向传导 → 池聚合 → 温度化）。walk-forward fd 8联赛×4季无前视拟合。

消融线：bootstrap CI 下界>0 才启用，否则 T=1 落盘

步骤 3：HAFU 半场参数升级（design §6）

参数 1 联赛级半场占比 s（β 收缩 200 球，clamp[0.3,0.6]，替代硬编码 0.45）；参数 2 半场 ρhalf（矩估计，clamp[-0.2,0.2]，复用 dc_tau）。

回退：日韩瑞沙无半场列 → 全局；缺 half_share.json → 0.45/ρ=0（现状）
