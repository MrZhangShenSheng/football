统一比分分布引擎 score-engine 设计

日期 2026-09-07 · 状态：架构已拍板（大哥 2026-09-07 评审通过），数据地基两项侦察待回填（§四） · 实施计划：docs/plans/2026-09-07-score-engine-p0-plan.html · 开发者 sszhang

§一 背景与目标

当前比分预测分散在两条哲学对立的轨道，且各有短板：

  • EV/频率链（freq_band + score_ev）：形状来自联赛真实赛果频率（经验贝叶斯三层收缩 + λ平移高斯核），但位置估计 λ 用手写乘法模型，精度有限。
  • 剧本链（narrative.py 轨道N）：五层叙事链的第五层"剧本层"只有风格模板粗估（SCRIPT_PROB_EST = 0.25），P1.5 的"λ推导接 dc_predict"未落地——缺的就是比分分布引擎这块芯。

目标：建统一比分分布引擎 score-engine，全链唯一的比分矩阵出口（7×7），三场景共用：

  1. 剧本轨（narrative）：剧本比分从矩阵推导，分歧度有了精确计算基础；
  2. EV轨（freq_band）：平移目标 λ 升级（形状哲学不变）；
  3. 独立比分报告：每场 Top3/5 比分 + 概率 + 体彩 CRS 赔率对照。

§五 三出口设计

出口输入产出边界
① 剧本轨（P1 落地）score_matrix + 剧本域剧本比分 = SCRIPT_UNIVERSE 内 argmax；分歧度 = 叙事矩阵 vs 市场矩阵 JSD（只做选场排序）仍不算 EV、不参考市场定价出票——市场矩阵只喂分歧度，边界写死
② EV轨（freq_band λ升级）λ_fused平移目标 λ 从手写乘法模型 → λ_fused；形状仍联赛真实频率；SURVIVE_Q/T_AXIS_GUARD 护栏不动降级链：λ_fused 不可得 → 退手写乘法模型 + 标旗
③ 独立比分报告score_engine.matrix 全量每场 Top3/5 比分 + 概率 + 体彩 CRS 赔率对照 + EV（报告轨可算，单独标注）口径标记 fused/dc_only 逐场展示；产出节奏：独立命令起步

§六 验证：两段式结构 + 生死线

为什么两段式：体彩五池存档仅 14 天，fused/market_only 线的长历史 walk-forward 做不了；历史市场源只有 fd 收盘（无比分池）。一段式验证在设计上不成立。
段数据市场源回答
段A 历史代理回测fd 联赛多季赛果fd Pinnacle 收盘（三向+OU2.5 反推）方向对不对（fused / market_only / dc_only / freq_band现状 四线，CRS TOP1/3/5 命中率 + TTG 带 RPS）
段B 影子前向对照体彩在售场次，一个月起体彩五池反推（真实出票口径）体彩口径下转不转正（影子票 CLV/命中率，A/B 双口径 spec_name 区分）

判据（含降级条款）

  1. 生死线：段A中 fused 不敌 market_only 或 dc_only 任一基线 → 消融铁律回退最简单口径，score_engine 只保留报告出口；
  2. CLV 判据降级声明：fd 无 Pinnacle 比分收盘，CRS-CLV 永远无真值锚——用三向/大小边缘 CLV 代理 + fused 矩阵 vs pinClose 三向分布偏差校验，报告注明；
  3. 样本功效：CRS TOP3 命中率 ~35%，月百场标准误 ±4~5pp，一个月分不出显著——段B 判据降级为"不显著劣 + 方向正"，或延长对照期；
  4. λ融合权重以段A重标定为准，0.29/0.71 仅作初始值。

§八 上线路径（影子是必经站）

出口路径
剧本轨直接进影子层（track:"N" 本在影子验证期）
EV轨 freq_band λ升级影子对照一个月 A/B（新旧口径并行冻结结算），不动推荐卡主链
报告直接产出，不设门槛（纯信息，逐场标口径）

入推荐卡切换判据（三条全过）：① 段A四线对照 fused 不输任一基线；② 段B影子对照不劣于现状口径；③ 两条都过 → freq_band 切 λ 源 + 剧本轨矩阵转正。任一不过 → 消融铁律回退，只留报告出口。
